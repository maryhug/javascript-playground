  <h1>JavaScript Playground</h1>
  <p>Playground interactivo de JavaScript vanilla con múltiples módulos funcionales en una sola página. Cada módulo demuestra conceptos clave del DOM, eventos y lógica de programación.</p>

</div>

---

## Módulos incluidos

| Módulo | Descripción |
|---|---|
| Validación de nombre | Saludo personalizado con detección de escritura en tiempo real |
| Verificación de edad | Comprueba elegibilidad con feedback visual en el botón |
| Contador | Incremento, decremento y reset con colores según el valor |
| Gestor de tareas | Agregar, completar y eliminar tareas con contador de pendientes |
| Modo oscuro | Toggle de tema con persistencia en `localStorage` |
| Consola de logs | Logger visual en tiempo real con niveles: `info`, `success`, `warn`, `error` |

## Tecnologías

- JavaScript vanilla (sin frameworks)
- HTML5 semántico
- Tailwind CSS para estilos

## Uso

Abre `index.html` directamente en el navegador o usa **Live Server** en VS Code.

```bash
git clone https://github.com/maryhug/javascript-playground.git
```

## Estructura del proyecto
```
javascript-playground/
├── index.html
└── script.js
```
